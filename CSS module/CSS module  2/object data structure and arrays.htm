Object Data Structure and Array Demo

This page demonstrates creating JavaScript objects and arrays, accessing values via object keys and array indices, and using methods like join() and pop().

1. Object Data Structure

Accessing data using object keys:

const student = {
    name: "Alex",
    age: 20,
    course: "Computer Science"
};

// Accessing properties using keys
document.getElementById('obj-output').innerText = 
    `Name: ${student.name}, Age: ${student["age"]}, Course: ${student.course}`;

2. Array Access by Index Value

Accessing individual elements using zero-based indices:

const fruits = ["Apple", "Banana", "Cherry", "Date"];

// Accessing by index
document.getElementById('array-index-output').innerText = 
    `First element (index 0): ${fruits[0]} | Third element (index 2): ${fruits[2]}`;
